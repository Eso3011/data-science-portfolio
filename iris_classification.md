# Iris Flower Classification (CodeAlpha Internship)

## Overview
This project was completed as part of the CodeAlpha Data Science Internship. The objective was to classify Iris flower species using supervised machine learning techniques.

## Dataset
The dataset contains 150 samples across three species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Exploratory Data Analysis
Visualization showed strong separability between species, especially in petal measurements.

## Models Used
- Logistic Regression
- Random Forest Classifier

## Results
Both models achieved 100% accuracy on the test dataset.

## Skills Demonstrated
- Data preprocessing
- Feature scaling
- Classification modeling
- Model evaluation
- Confusion matrix interpretation
